# CYBERTRMX

Mobile-first red-node operations console deployed as a static GitHub Pages PWA.

## Live URL

`https://drmacze.github.io/cyberxtrmx/`

## Architecture

- Static HTML/CSS/JavaScript in `public/`
- Stateful local terminal using `localStorage`
- Installable PWA for iPhone Home Screen
- Public IP metadata lookup through `ipwho.is`
- Multi-stage local package, source, session, recon, trace, audit, and mutation workflows
- GitHub Actions Pages deployment in `.github/workflows/pages.yml`

## Safety boundary

The interface is an authorized lab environment. It does not request, test, capture, or change live credentials. Game identity output is generated by the staged local model; IP intelligence is public network metadata and approximate.

## Development

Open `public/index.html` with a static web server. No build step or dependency installation is required.
